# Not An Old Pulse

Minecraft мод, разработанный вдохновления старому Pulse Visuals

> [!WARNING]  
> 
> Не все функции работают, так как это еще альфа версия.
> 
> Весь проект - навайбкоженный ужас, данный проект был сделан чисто как эксперемент.

## Описание

###  Главные фишки (Функционал):
- **Улучшенный HUD и рендер:** TargetHUD (информация о цели), динамический прицел (Custom Crosshair), и даже Dynamic Island (уведомления в стиле iOS).
- **Визуальные эффекты:** Плавный Motion Blur (размытие в движении), кастомные хит-эффекты (Hit Effects), след за игроком (Player Trail) и настройка положения рук (Viewmodel Handler).
- **Удобство и навигация:** Система вейпоинтов (Waypoints) для сохранения важных локаций и удобное кастомное меню (Custom Main Menu / Pause Menu).
- **Косметика и прочее:** Интеграция с Discord (RPC), система друзей, встроенный FullBright и забавные аксессуары (например, ChinaHat).

###  Известные проблемы
- Возможны просадки фпс в некоторых моментах
- Возможны конфликты с другими крупными модами на оптимизацию рендера (например, Sodium) при использовании Motion Blur.
- Гуишка может требовать дополнительных библиотек (MCEF) или скачиваться дольше на слабых ПК.
- Динамический остров иногда может перекрывать нестандартные элементы интерфейса от других модов.
- Кастомный прицел не выключается (будет пофикшено в следующих обновлениях)
- Большая часть функций не рабочая (будет пофикшено в следующие обновлениях)
- Музыка в динамическом острове не будет работать на системах Linux \ macOS
- Не работает перемотка трека в динамическом острове

## Установка
1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) для Minecraft 1.21.11.
2. Скачайте последний релиз мода (или соберите его самостоятельно).
3. Поместите скомпилированный файл `.jar` в папку `mods` вашей игры.
4. Для лучшего опыта, стоит скачать бесплатный [Pulse Visuals](https://pulsevisuals.pro/free) (по вашему желанию)

## Требования к сборке проекта

- **Minecraft версия**: 1.21.11
- **Fabric Loader**: 0.19.5
- **Java**: 21 и выше
- IntelliJ IDEA

## Сборка из исходников

Для самостоятельной сборки проекта вам потребуется **Java 21**.

1. Склонируйте репозиторий:
```bash
git clone https://github.com/ablivity/Not-an-old-Pulse.git
cd Not-an-old-Pulse
```

2. Запустите сборку с помощью Gradle:
- **На Windows:**
  ```bash
  gradlew.bat build
  ```
- **На Linux / macOS:**
  ```bash
  ./gradlew build
  ```

После успешной сборки готовый `.jar` файл будет находиться в директории `build/libs/`.
